# v0.5 – Manueller Export-Regressions-Test

## Ergebnis

Die bestehenden Exportfunktionen wurden am 16.08.2026 manuell in Chrome mit
dem gebündelten Userscript und Tampermonkey geprüft. Alle getesteten Formate
funktionierten erfolgreich.

## Geprüfte Funktionen

| Funktion | Ergebnis |
| --- | --- |
| Copy Text / Clipboard | bestanden |
| JSON | bestanden |
| Markdown | bestanden |
| HTML | bestanden |
| Screenshot / PNG | bestanden |

Die Exporte wurden aus einer normalen ChatGPT-Unterhaltung ausgelöst und die
jeweiligen Ergebnisse lokal geöffnet bzw. eingefügt.

## Technischer Nachweis

Zusätzlich bestanden:

```text
pnpm lint
pnpm test
pnpm test:core
pnpm test:extension
pnpm build
```

Damit sind sowohl die neue Destination-Abstraktion als auch die bisherigen
Renderer und der Extension-Build regressionsgeprüft.

## Nicht Bestandteil dieses Tests

Der Mehrfach-/ZIP-Export wurde in diesem Durchlauf nicht ausgeführt. Er bleibt
als eigener Batch-Test für den Robustheitsmeilenstein v0.7 vorgesehen, um
keinen großen unbeabsichtigten Export aller Chats auszulösen.
