# v0.4 – Manueller Abnahmetest

## Ergebnis

Der manuelle Chrome-Test wurde am 15.08.2026 mit einer frisch erstellten
ChatGPT-Unterhaltung durchgeführt. Der Export über das Popup **„Aktuellen Chat
herunterladen“** war erfolgreich.

## Geprüfter Ablauf

1. Extension als entpackte MV3-Erweiterung in Chrome geladen.
2. Neue Unterhaltung unter `chatgpt.com/c/<conversation-id>` erstellt.
3. Eine Testnachricht gesendet.
4. Extension-Popup geöffnet.
5. Raw-Download ausgelöst.
6. JSON-Datei lokal geöffnet und technisch geprüft.

## Prüfergebnis

| Prüfung | Ergebnis |
| --- | --- |
| Datei wurde heruntergeladen | bestanden |
| JSON ist parsebar | bestanden |
| Titel vorhanden | `Test für Export` |
| Conversation-ID vorhanden | bestanden |
| Mapping vorhanden | 4 Knoten |
| Originale Conversation-Felder erhalten | 34 Top-Level-Felder |
| Externer Versand | nicht erfolgt |

Der Inhalt wurde als Roh-JSON gespeichert. Die Normalisierung wurde nur für
die Dateinamenableitung verwendet und nicht zum Rekonstruieren des Downloads.

## Bekannter Zwischenbefund

Der erste Test mit einer älteren Unterhaltung lieferte HTTP 404. Die Ursache
war die fehlende Session-Authentifizierung im Extension-Adapter. Nach der
Übernahme der bestehenden Token-Abfrage aus dem Userscript (`/api/auth/session`
sowie `Authorization`/`X-Authorization`) funktionierte der Test mit der neuen
Unterhaltung erfolgreich.

## Abgrenzung

Der im ChatGPT-Interface sichtbare Button **„In PDF konvertieren“** gehört nicht
zu diesem Projekt und war für den Raw-JSON-Test irrelevant.
