# v0.3 – Chrome-MV3-Extension-Shell

## Ziel

v0.3 schafft die eigenständige Chrome-Laufzeit, ohne bereits die fachliche
Capture- oder Download-Logik vorwegzunehmen. Der bestehende Userscript-Build
bleibt unverändert baubar; die neue Extension wird separat erzeugt.

## Laufzeitgrenzen

```text
ChatGPT-Seite
    │
    ├── Page Bridge       (page world, nur Nachrichten)
    │
    └── Content Script    (isolated world)
             │
             ▼
       Service Worker     (Extension-Runtime)
             │
             └── Popup     (Verbindungs-Sanity-Test)
```

Die Nachrichten sind typisiert, über einen festen `source`-Wert markiert und
werden an jeder Grenze validiert. In v0.3 werden keine Authentifizierungsdaten
oder Conversation-Inhalte an externe Ziele gesendet. Die Testnachricht ist
absichtlich synthetisch.

## Berechtigungen

Die Manifest-Datei beschränkt `host_permissions` und Content-Script-Matches
auf `chatgpt.com` und `chat.openai.com`. Es gibt keine globale
`*://*/*`-Berechtigung. `storage` ist für die kommende konfigurierbare
Extension-Infrastruktur reserviert.

## Lokaler Build und Test

```text
pnpm build:extension
pnpm test:extension
```

Der Build erzeugt `dist-extension/`. Diese Ausgabe kann in Chrome unter
`chrome://extensions` als „Entpackte Erweiterung laden“ geladen werden.

## Bewusste Grenzen

- Noch kein echter ChatGPT-Capture.
- Noch kein Raw-Download.
- Noch keine externen Destinations.
- Der bisherige Userscript-Build bleibt für die Übergangsphase erhalten.

Diese Punkte gehören in v0.4 und spätere Meilensteine.
