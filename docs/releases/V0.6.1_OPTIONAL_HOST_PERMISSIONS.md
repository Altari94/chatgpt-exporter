# v0.6.1 – Optionale Endpoint-Berechtigungen

v0.6.1 schließt den Berechtigungsfluss für externe HTTP-Destinations ab.

## Warum diese Version nötig ist

Chrome verlangt für Cross-Origin-Requests aus einer Extension passende Host-Berechtigungen. Eine generische Exporter-Extension kann den Zielhost aber nicht im Voraus kennen. Deshalb sind HTTP- und HTTPS-Hosts als **optionale** Berechtigungen deklariert.

Die Berechtigung wird nicht bei der Installation pauschal aktiviert. Sie wird erst angefordert, wenn der Nutzer einen Endpoint speichert oder einen Versand auslöst. Angefordert wird nur die konkrete Endpoint-Origin, zum Beispiel:

```text
https://second-brain.example/*
```

Lehnt der Nutzer ab, bleiben Download und alle anderen Funktionen nutzbar; nur die HTTP-Destination bleibt deaktiviert.

## Nutzerfluss

1. Endpoint eintragen.
2. **Endpoint speichern** klicken.
3. Chrome zeigt die Berechtigungsabfrage für die konkrete Domain.
4. Nach Zustimmung kann der Endpoint getestet und per Klick verwendet werden.
5. Wird die Berechtigung abgelehnt oder später entzogen, zeigt die Extension einen verständlichen Fehler.

## Sicherheitsentscheidungen

- ChatGPT-Host-Berechtigungen bleiben feste, notwendige Berechtigungen.
- Endpoint-Hosts sind optional und werden erst bei Bedarf angefragt.
- Es werden keine Zugangsdaten oder Tokens in der Extension hinterlegt.
- HTTPS wird für produktive/private Daten empfohlen.
- Es gibt weiterhin keinen automatischen Versand.
- Die Berechtigung kann in den Chrome-Erweiterungseinstellungen wieder entzogen werden.

## Open-Source-Relevanz

Jeder Nutzer kann seinen eigenen Zielhost verwenden und die Berechtigung selbst bestätigen. Das Projekt benötigt keine persönliche Serveradresse und keine projektspezifische Konfiguration. Die gleiche Schnittstelle funktioniert für lokale Dienste, private Server und Community-Integrationen.

Die optionalen Wildcard-Muster im Manifest sind nur der technische Rahmen, damit Chrome zur Laufzeit eine konkrete Origin anfordern kann; sie gewähren nicht automatisch Zugriff auf alle Hosts.
