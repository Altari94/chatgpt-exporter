# v0.4 – Ein-Klick-Raw-Download

## Ziel

v0.4 liefert den ersten Kernnutzen des Forks: Auf einer normalen
ChatGPT-Unterhaltung kann der aktuell geöffnete Chat aus dem Extension-Popup
mit einer Nutzeraktion als unverändertes JSON heruntergeladen werden.

## Ablauf

```text
Popup: Aktuellen Chat herunterladen
        │
        ▼
Content Script
        │  URL /c/<conversation-id> prüfen
        │  GET /backend-api/conversation/<id>
        ▼
Raw-Capture
        │  Response-Text unverändert sichern
        │  JSON nur zusätzlich parsen
        ▼
Lokaler Download
        └── <Titel>--<Conversation-ID>.json
```

Der Service Worker erhält weder Session-Token noch Conversation-Inhalt. Die
Anfrage bleibt im Content Script auf der ChatGPT-Seite, und der Download wird
als lokaler Blob über den Browser ausgelöst.

## Fehlerverhalten

Die Quelle unterscheidet mindestens folgende Fälle:

- nicht unterstützte Seite
- fehlende oder abgelaufene Anmeldung (`401`/`403`)
- nicht gefundene Unterhaltung (`404`)
- Netzwerkfehler
- leere oder ungültige JSON-Antwort

Fehler werden im Popup als verständlicher Status angezeigt. Ein erfolgreicher
Download wird erst gemeldet, nachdem der Browser-Download ausgelöst wurde.

## Dateiintegrität

Der Dateitext stammt ausschließlich aus `raw.text` des Capture-Modells. Die
Normalisierung dient nur dazu, den Titel für den Dateinamen abzuleiten. Der
JSON-Inhalt wird nicht aus der normalisierten Struktur rekonstruiert.

## Manuelle Abnahme

```text
pnpm build:extension
```

1. `dist-extension/` unter `chrome://extensions` als entpackte Erweiterung
   laden.
2. Eine normale Unterhaltung unter `https://chatgpt.com/c/...` öffnen.
3. Extension-Popup öffnen und „Aktuellen Chat herunterladen“ wählen.
4. Die heruntergeladene Datei öffnen, JSON-Syntax prüfen und den Titel sowie
   die Conversation-Struktur kontrollieren.
5. Eine nicht angemeldete oder nicht unterstützte Seite prüfen und die
   verständliche Fehlermeldung kontrollieren.

Share-Seiten und Batch-Exporte sind bewusst noch nicht Teil dieses Meilensteins.
