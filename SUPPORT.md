# Support

Before reporting a problem, update the extension, reload it at `chrome://extensions`, and retry on a normal `https://chatgpt.com/c/{id}` conversation.

When opening an issue, include the extension version, Chrome version, URL type (never the private conversation content), exact steps, the visible error, and whether the issue concerns capture, package download, media, batch export, or an HTTP destination.

For security-sensitive reports, follow [SECURITY.md](./SECURITY.md) instead of opening a public issue.
